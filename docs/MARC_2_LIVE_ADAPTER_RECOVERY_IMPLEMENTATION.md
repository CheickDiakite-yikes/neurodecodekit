## Additive Executor

The standard-library module is new. It does not import, call, edit, copy, or
expose either consumed private executor or consumed output root. Its four CLI
commands are:

```text

qualify   run generated and mocked refusal qualification
inspect   summarize an aggregate LA2 report
execute   require exact green implementation evidence, then consume one run
```

The `execute` path has no generic source or output override. It binds one
literal 418,755-byte, mode-`0600`, SHA-256-identified structural manifest and
one new v2 output root. Before content access it requires:

1. the exact decision, native registry, and distinct FW1B certificate;
2. a clean exact implementation commit descending from the green decision;
3. exact remote CI and both job identities;
4. one thread, one worker, one numerical job, at least 15 GiB free disk, and
   bounded load/RSS;
5. no-follow path-component, owner, mode, regular-file, size, and identity
   checks; and
6. a newly created consumed marker before the one permitted content open.

The reader supports short reads without reopening. It computes size and
SHA-256 in that same sequential pass, rejects duplicate JSON keys, and checks
the open descriptor against the preflight identity. Only then may it call the
exact green LA1 adapter once and the frozen selector once. A success writes one
mode-`0600` private structural selection and one aggregate target-free report.
Every failure after consumption is final and emits only an aggregate receipt.

Archive local headers, archive members, payload bytes, signals, events,
targets, labels, channels, quality values, features, caches, models,
