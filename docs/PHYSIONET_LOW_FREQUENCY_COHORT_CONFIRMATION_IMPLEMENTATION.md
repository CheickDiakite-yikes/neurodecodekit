## Capability Implemented

The implementation adds three dry-run-first commands:

```bash
neurodecode physionet-low-frequency-acquire
neurodecode physionet-low-frequency-cohort
neurodecode score-physionet-low-frequency-cohort
```

The first command implements a standard-library-only, no-redirect, no-retry
acquisition layer. It reverifies the 15 registered metadata documents before
requesting any EDF body, streams exactly 72 allowlisted EDFs sequentially,
checks the exact byte count and official SHA-256 once per local file, promotes
one complete isolated bundle atomically, and writes bounded receipts. It does
not import MNE or another EDF reader.

The second command implements the registered sequential MNE reader, exact
64-channel and geometry checks, 160 Hz and T0/T1/T2 annotation checks, causal
continuous-run common-average reference and 0.5-4 Hz filtering, compact 5C
features, and a three-part target firewall:

- 720 fit rows with run-03/04/07/08 labels;
- 360 target-free run-11/12 prediction rows;
- one separately sealed 360-target scorer input.

The predictor fits exactly 12 registered participant-specific templates per
participant, or 144 total parameter-update runs. It creates exactly 18
condition families, 216 participant-condition prediction sets, and 3,240
individual private predictions. The public freeze contains only aggregate
configuration, split, source, derivative, private-payload, and per-condition/
participant prediction hashes. It contains no individual prediction,
probability, target, or participant outcome.

The third command implements the isolated aggregate scorer. It can open the
same 360 sealed targets only after the combined prediction freeze is committed,
pushed, and remotely green. It verifies every private prediction against its
frozen hash and event/participant/run identity, computes only aggregate
condition and participant-level inference summaries, applies the frozen
`WO9R-R0` through `WO9R-R4` router, writes one public result, and permits no
post-target fit, selection, threshold, channel, or model update.

## One-Shot Ordering

Two access-order invariants are explicit and tested:

1. The real analysis writes its no-rerun consumed marker before the first
   registered bundle inspection, EDF hash, header read, annotation read, signal
   read, or target-firewall operation.
2. The scorer writes its no-rerun consumed marker before the first private
   prediction, target-free derivative, or sealed-target hash/open.

An integrity or resource failure after either marker parks the registered stage.
It does not create a retry path.
