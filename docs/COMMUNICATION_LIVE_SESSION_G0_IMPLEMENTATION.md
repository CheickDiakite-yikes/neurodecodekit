## Purpose

This milestone implements the missing deterministic boundary between the
existing immutable `SourceChunk` transport contract and a future causal
communication decoder. It proves interface and state-machine behavior with
fictional streams and a deterministic fake processor. It does not read EEG,
infer intended text, train a model, contact a provider, or operate a device.

## Implemented Capability

`LiveSession` now:

1. accepts only validated `SourceChunk` values and binds source, correction
   ledger, processor configuration, model, decoder, and policy identities;
2. enforces exact source generation, sequence, sample, and timestamp
   continuity with explicit gap and reconnect transitions;
3. buffers fixed 16-sample causal frames, applies a 32-sample warm-up to every
   generation, and reports the first eligible output boundary;
4. keeps provisional output revocable and commits a symbol only after three
   eligible stable updates, with blank or inactive rearm before repetition;
5. clears causal processor and stability state across gaps and reconnects;
6. refuses target, label, reference-text, scorer, or probability leakage;
7. snapshots and restores complete bounded state with an exact self-hash and
   externally supplied semantic-prefix expectation; and
8. applies a transaction boundary so a refused chunk cannot partially mutate
   the session or processor object.

The sidecar CLI exposes `plan`, proof-gated `qualify`, and bounded `inspect`.
There is no real stream, device, model, network, or provider adapter.
