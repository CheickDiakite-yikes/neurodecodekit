## Implemented Boundary

The module validates one generated source in this order:

1. exact contract, fixed inputs, green proof, and source envelope;
2. every row, path, ZIP declaration, task identity, and unique member name;
3. every recognized four-companion bundle;
4. exact 1,025 regular-file and 202 directory counts;
5. every recognized participant against the frozen taxonomy;
6. exact 195 eligible bundles and exact participant/session distribution;
7. a boolean public-238 compatibility status without exposing another count;
8. quarantine of all known ineligible groups;
9. unchanged rank, split, reservation, prefix selection, and final identity
   validation.

Only the prior global full-bundle arithmetic assertion is not called. The
stronger exact eligible-map function remains unchanged and is executed before
selection. The module has `plan`, `qualify`, and `inspect`; it has no
`execute`, generic source/URL argument, private root, output root, ignored-path
reader, or consumed-state reader.
