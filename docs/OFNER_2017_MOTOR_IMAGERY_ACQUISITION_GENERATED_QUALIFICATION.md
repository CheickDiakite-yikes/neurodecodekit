## Why This Milestone Exists

The source-selection pass chose 150 original NEMAR GDFs because they retain
the reported EOG and hand/arm movement channels needed to challenge cheaper
non-neural explanations. Before requesting one real byte, the acquisition
boundary needed to solve the transport problem that stopped the Dreyer lane:
NEMAR's stable `bytes_url` identifies a file, but the manifest's expiring
signed `url` is what can carry its bytes.

This implementation treats those roles separately. Stable identity is the
versioned path, byte count, SHA-256, and `bytes_url`. The signed URL is accepted
only as a short-lived transport capability after its HTTPS host, object key,
embedded size and digest, query allowlist, expiry, and signature shape match
the stable identity.

## Implemented Boundary

The standard-library core now:

1. parses JSON strictly, rejecting duplicate keys, non-finite constants,
   alternate encodings, and oversized manifests;
2. canonicalizes the manifest by removing only each row's volatile `url`;
3. requires the complete 15-participant by 10-run motor-imagery GDF matrix;
4. rejects missing, duplicated, expanded, ambiguous, or target-bearing rows;
5. validates stable NEMAR byte URLs and signed S3 object URLs independently;
6. streams opaque injected bytes sequentially under network and disk caps;
7. verifies every byte count and SHA-256 before one atomic promotion;
8. refuses existing outputs, symlink components, wrong thread settings,
   partial streams, extra bytes, corruption, and receipt overflow; and
9. exposes no network client, redirect follower, GDF parser, or real-payload
   execution command.

The CLI defaults to an inspectable dry-run plan. Its sole runnable mode is
`--qualify-generated`; there is deliberately no `--execute` argument.

## What This Proves

It proves that the intended Ofner inventory can be represented as one exact
matrix and that stable identity can survive signed-URL refresh while a bounded,
atomic, transport-injected writer rejects the generated failure modes tested.
It also removes direct public-URL redirect behavior from the future acquisition
core: a later live wrapper must explicitly obtain and validate the manifest's
one-hour signed object capability.

## What This Does Not Prove

The generated bytes are not EEG. This result does not establish that a real
Ofner GDF is reachable, readable, exposes the reported 96-channel measurement
surface, contains usable trials, carries neural information, beats no-signal
or nuisance controls, generalizes to an unseen person, originates in motor
cortex, represents movement intention, decodes thought or language, or works
live or on portable hardware.

Because Ofner reports no recorded EMG, even a later positive result cannot by
itself establish independence from all muscle activity.
