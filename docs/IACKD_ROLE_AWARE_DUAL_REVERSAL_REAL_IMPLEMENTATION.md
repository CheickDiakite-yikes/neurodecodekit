## Fresh Sequential Stream

The real acquisition path uses only the committed OpenNeuro inventory and
reverifies the pinned dataset description, changes document, and two listing
pages. It rejects redirects, retries, substitutions, transfer encoding,
content encoding, status drift, URL drift, size drift, ETag drift, and body
drift.

The executor downloads one 10-object run group at a time. Each object is
written once while SHA-256 and ETag-compatible MD5 are accumulated in the
same pass. MNE parses only the current run group. The raw object group is
removed only after its model, sealed-target, and physiology derivatives are
atomically promoted. At most one raw run group can coexist with derivatives;
the measured inventory maximum is 82,064,564 bytes.

Thirty electrode/coordinate pairs are handled separately and retained only in
memory while the stream runs. Geometry accepts either three finite source
coordinates or three explicit unavailable values; a partially available
coordinate is refused. The fixed 26 predictive EEG channels must have finite
geometry. Optional M1/M2 and the source-declared HEOG, VEOG, and Trigger
controls remain nonpredictive and may declare geometry unavailable.

All MNE objects close in a `finally` block, including parser and reconciliation
failures. Invocation disk accounting walks only the new private execution root
and rejects symlinks or nonregular files. Cleanup is restricted to a child of
the invocation-created temporary root and refuses every preexisting or escaping
path.

## Target Firewall

The private derivatives are physically separated by purpose:

- fit model shards contain fit signals and fit labels;
- final model shards contain final signals, identities, groups, and timing but
  no action or cue target field;
- sealed scorer shards contain only final identities, measured actions, and
  exact opposite cue surrogates; and
- physiology shards contain target-free traces and aggregate-ready measures.

The model-stage loader enumerates only the model directory. It does not list,
stat, hash, or open the sealed directory. A separate scorer loader opens all
sealed targets only after the aggregate prediction freeze is committed,
pushed, and remotely green. The scorer verifies identical item order and the
exact relation `cue_surrogate = 1 - actual_action` before evaluating either
view.

## Frozen Model Matrix

The implementation preserves the preregistered classical matrix: 11 fits and
15 prediction sets for each arm and participant-hand unit, totaling exactly
660 parameter-update fits, 900 target-blind inference calls, and 900 prediction
sets. No family, threshold, participant, arm, run, channel subset, or control
is selected after final targets are visible.

Private predictions use deterministic canonical ordering and a deterministic
NPZ payload. Loading the payload recomputes every condition hash, final-item
binding, split hash, canonical prediction hash, and dimensional invariant. The
public freeze publishes aggregate hashes and counts only. It contains no
individual prediction, probability, target, participant outcome, local path,
or model coefficient.

The scorer applies the registered `IACKD2-R0` through `IACKD2-R5` router.
Both `C2I` and `I2C` arms must pass. One arm cannot rescue the other, and the
participant-level weaker-arm margin remains primary. Controls and target-free
physiology are descriptive gates and never select a model or threshold.
