## Additive Surface

The new module is:

```text
src/neurodecodekit/datasets/marc2_dynamic_live_selection.py
```

Its only commands are `plan` and `qualify`. There is no `execute` mode, path,
URL, private root, output root, network client, archive reader, neural reader,
target interface, model, trainer, predictor, freezer, scorer, stream, device,
or hardware surface. The implementation uses only the standard library and
existing dependency-free MARC2 modules.

The module imports no consumed executor and does not patch VR2. It calls VR2's
exact full-source validation function, then calls the existing target-free
prefix selector without calling VR2's fixture-exact `_assert_selection`.

## Dynamic Invariants

The adapter accepts a result only when:

- selected participants are the frozen rank's maximal contiguous prefix;
- selected count is between 12 and 19;
- each subject contributes three `ses-01` fit runs and three `ses-02` heldout
  runs, each with all four structural companions;
- fit and heldout identities are disjoint and row-random splitting is false;
- every row's reservation formula recomputes exactly and the row sum equals
  the aggregate selected reservation;
- selected bytes are at or below the unchanged 8 GiB cap;
- either all 19 fit or the exact next ranked subject is measured and exceeds
  the remaining reservation;
- source input remains byte-canonical and unaliased; and
- target, label, quality, outcome, neural, prediction, and score fields are
  absent.

Selected count, selected bytes, and selection identity are measured outputs.
No generated expected-selection object is consulted.

## Live Semantics Repair

After invariant validation, rows are deep-copied into a new private in-memory
manifest with:

```text
source_id:       freewill_23_live_central_directory
proof_posture:   target_free_live_structural_selection_no_payload_or_scientific_value
source hash:     live_source_canonical_sha256
selector hash:   selector_contract_sha256
dynamic hash:    dynamic_selection_contract_sha256
```

The selection identity and complete private-manifest hash are recomputed and
revalidated. Generated source labels and `generated_inventory_sha256` are not
accepted on live-derived rows.

This proves the interface behavior on generated live-shaped manifests. It
does not claim that a new private source has passed the interface.

## Aggregate Route Boundary

An upstream validation refusal retains at most one allowlisted route code from
`MARC2VR2-F01` through `MARC2VR2-F08`. The upstream reason, predicate value,
participant identity, member name, path, and exception context are discarded.
An unknown upstream route fails closed without echoing its value.
