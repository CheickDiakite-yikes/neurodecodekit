## Revision Evidence That Is Not Enough

- An `ETag` is ordinarily a representation validator. Weak, CDN-generated,
  compression-specific, query-specific, and page-specific values are not
  source-global revisions. Preserve raw bytes; never strip `W/` or quotes.
- `Last-Modified` is mutable, coarse, and proxy-sensitive. It cannot be the
  sole admission key.
- A schema ID, API version, or frontend build identifies parser compatibility,
  not the indexed records.
- A body SHA-256 identifies exact observed bytes, not a source-issued semantic
  revision. It is admissible only inside the explicitly named complete opaque
  snapshot mode.
- `HEAD` is not interchangeable with the registered `GET` or `POST`
  representation.

Missing, ambiguous, conflicting, narrower-than-traversal, or mixed-scope
evidence is false.
