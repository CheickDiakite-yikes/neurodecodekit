## Target Firewall

Fit labels exist only in the model-stage fit arrays. Final model arrays contain
item, participant, hand, run, and feature fields, but no target, label,
direction, condition, trajectory, prediction, probability, score, or outcome
field.

The model function accepts a strict six-field model-stage object. It refuses the
outer derivative object because that outer object also owns a separate scorer
stage. The scorer stage holds generated action and cue-surrogate targets, but it
is not passed to model fitting or prediction.

Before the scorer may inspect its generated targets, it recomputes all 900
prediction-set hashes, the canonical private prediction hash, the target-free
split hash, and the final-item binding. A malformed matrix, changed prediction,
changed freeze, missing set, target alias, or item mismatch fails closed.

This is a function and artifact boundary, not an operating-system sandbox. It
qualifies the interface mechanics only.
