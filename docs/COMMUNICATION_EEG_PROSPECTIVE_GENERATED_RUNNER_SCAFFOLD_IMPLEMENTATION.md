## What this milestone adds

The additive runner introduces:

- sequential spawned model and scorer children under a sanitized environment;
- one-thread numerical enforcement and zero credential or proxy propagation;
- a reduced two-replay development route with a complete 15-digest canonical
  surface and same-host replay comparison;
- continuous process-tree RSS sampling where `ps` is available, normalized
  child-reported peak RSS, a shared timeout, and fail-closed resource caps;
- no-follow directory traversal and hard-link-based no-replace public result
  publication;
- invocation-owned temporary payload cleanup with zero retained generated
  payload after the development proof;
- an activation-locked official entry point and an independent sidecar CLI;
- a deterministic registry-backed mutation scaffold covering all 70 exact
  refusal family names once per replay, with exact wrappers and unchanged
  transaction-state hashes.

The reduced development test uses three fictional participants per cohort. Each
replay performs six participant-held-out folds, 90 compact classifiers, 90
temperature fits, 12 endpoint-specific residualizers, 204 prediction sets, and
13,056 target-blind prediction rows. Two replays therefore make 140 structural
refusal observations, four synthetic target deliveries, and four synthetic
aggregate scores. These counts are development measurements, not the frozen
official 42-person schedule.

## Deliberately unresolved

This milestone is a scaffold, not the complete official coordinator:

1. The current 70-family mutation scaffold mutates typed registry invariants.
   It does not yet route every family through a domain-specific causal, sensor,
   privacy, storage, prediction, scorer, or live validator. It cannot satisfy
   the official malformed-input acceptance gate by itself.
2. The reduced path transfers generated trial and prediction objects through a
   process pipe. The full 91,392-row official path must instead use bounded
   no-follow files or anonymous descriptors so the coordinator does not duplicate
   the private prediction surface in memory.
3. The scorer still receives green-freeze state through development booleans.
   Official scoring requires a cryptographically bound, no-follow-opened freeze
   attestation and a scorer process with no fitting capability.
4. The `getrusage` RSS fallback is sufficient for bounded local development
   accounting but not a substitute for continuous process-group monitoring in
   the official execution.
5. No durable official consumed marker, activation artifact, official replay,
   or public qualification result exists.

Those are explicit activation blockers. They will be resolved additively rather
than by weakening the registered contract.
