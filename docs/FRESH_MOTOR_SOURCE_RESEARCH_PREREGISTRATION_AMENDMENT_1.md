It found five blockers:

   combination;

3. the frontier called all authorities false while enabling an artifact packet;

`FMSR1-v0` performed no network, payload, model, target, score, device, release,

## Frozen Scientific Question

> In completely unseen people, does central EEG add motor-task information
> beyond the joint combination of recorded eye activity, task-relevant muscle
> activity for every relevant effector, posterior EEG, cue, and timing
> structure, relative to matched deranged central EEG?

Speech, language, and communication sources cannot satisfy this motor lane.
Every consumed source named by v0 remains excluded.

## Ordered Source Routing

1. `DISCOVERED_CANDIDATE`: returned by the frozen universe and query grammar.
2. `ELIGIBLE_FOR_METADATA_RESEARCH`: official index-level evidence makes every
   exact predicate field explicit, including complete canonical identity,
   nonoverlap, motor task, EEG, EOG, all-relevant-effector EMG, at least ten
   participants, geometry, event semantics, license, bounded bytes, reader,
   and every deterministic sort field. Query-term matching alone is
   insufficient. This route may be proposed for one candidate-specific,
   target-free metadata packet.
3. `FULL_CONFIRMATION_SOURCE`: only after that registered metadata pass verifies
   every hard gate. This route may be proposed for a later 256-byte opaque
   transport canary.
4. `PARTIAL_CONTROL`, `MECHANISTIC_BRIDGE`, `ENGINEERING_ONLY`, or `PARK`: a
   verified hard gate fails or remains unknown; the source cannot be promoted.

No current candidate occupies any route. `NO_QUALIFYING_SOURCE` means zero
eligible candidates after the complete frozen surface was traversed at the
packet-bound revisions. If any index or pagination path is incomplete or hits
a cap, the only outcome is `DISCOVERY_CAP_PARK`; partial results cannot be
ranked. Neither outcome can weaken the criteria.

## Canonicalization And Deterministic Selection

Each candidate ID is the NFKC-normalized, ASCII-trimmed concatenation of
`official_index_id`, `immutable_source_identifier`, and
`immutable_release_identifier`, separated by `::`. Empty components refuse.
Repeated hits for the same exact ID merge their sorted query evidence;
different indexes never merge without explicit shared immutable identity.

After complete traversal, every candidate is evaluated against every exact
predicate field in the machine contract. Unknown, missing, ambiguous, or
conflicting is false. All and only passing candidates enter one deterministic
ordering:

1. complete participant count, descending;
2. bilateral EMG coverage, then kinematic coverage, descending;
3. count of independent laboratory, device, and participant components,
   descending;
4. minimum trials per participant, descending;
5. storage headroom, descending; and
6. canonical candidate ID by code point, ascending.

All sort values are mandatory, so the last key is a total tie-break. The first
candidate alone may be proposed for one later target-free metadata packet.
Model performance, targets, participant outcomes, hidden payload properties,
download convenience, and desire for a positive result are forbidden inputs.

## Decisive Controls

The future scientific experiment must include the individual v0 controls plus:

- `joint_nuisance_only`: EOG, task-relevant EMG for every relevant effector,
  posterior EEG, cue, and timing features together; and
- `joint_nuisance_plus_deranged_central_EEG`: the same joint nuisance features
  plus fold-matched deranged central EEG.

The central-EEG arm, joint nuisance arm, and deranged joint arm must use the
same source-only calibration and participant-first scoring. Beating separate
controls cannot substitute for beating both joint comparators.

## Mandatory Shape Of The Later Discovery Packet

Because v0 is unaccepted, no future packet inherits requirements from it. A
later all-false discovery packet must bind every exact endpoint URL, official
revision, method, and allowlisted domain for all five indexes. It must preserve
the v1 canonicalization and ordering and stay within these ceilings:

- 128 total metadata requests and 32 MiB of response bodies;
- 8 MiB of retained public artifacts;
- 300 seconds, 256 MiB peak RSS, one CPU thread, and one worker;
- zero retries, at most 30 seconds per request, and at most three redirects
  whose every hop's scheme, host, port, and resolved method must match the
  exact allowlist before contact, with no method rewrite and an ordered
  redirect transcript; and
- complete pagination with every cursor or page identity recorded.

Pagination cycles, duplicate pages, truncation, response-cap breaches, or an
incomplete index produce `DISCOVERY_CAP_PARK`. Partial results cannot be
selected. Only the exact target-free identity, provenance, declared sensor,
participant, geometry, task, license, size, format, route, exclusion, and sort
fields allowlisted by the machine contract may be retained. Authentication,
cookies, private credentials, download URLs, payload/range/member/header
requests, and signal, event, annotation, target, or label reads are forbidden.
Failure is fail-closed with no substitution or rerun.
