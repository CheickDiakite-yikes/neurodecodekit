### 6. Positive controls, prediction freeze, and one score

2. For each development person, class, and window, average natural-log power
   equally over retained trials, every selected central channel, and exactly
   the 8-12, 12-20, and 20-30 Hz bands. Then average classes equally within the

3. In each leave-one-development-person-out fold, order central left-minus-right

   integer `k`, add positive `0.25*s[k]` only to dimension `k`, where `s[k]` is

### 7. Primary inference and hard decision

For each confirmation participant `i` and comparator edge `e`, compute the
equal-class mean natural-log loss within that participant, then weight
participants equally, and define:

```text
d[i,e] = LL[i, N + comparator[e]] - LL[i, N + correct central motor EEG]
```

The primary result is conjunctive. Every edge, including every fixed shift and
derangement, must have mean participant delta at least `0.020` nats/trial and
an exact one-sided participant sign-test `p <= 0.05`; ties count nonpositive.
The intersection-union rule needs no Bonferroni correction because the claim
passes only when every component null is rejected. One failed edge localizes a
confound and fails the central-attribution claim; edges are never averaged or
winner-selected.

Report deterministic participant-bootstrap 95% confidence intervals for each
mean delta and exact binomial confidence intervals for positive-participant
proportions. Report participant-macro balanced accuracy, Brier score, a fixed
ten-bin equal-width top-label expected calibration error, classwise recall,
missingness, and the no-signal prior as no-fit secondary evidence. The bins are
`[j/10,(j+1)/10)` for `j=0..8` and `[0.9,1.0]` for the last bin. Secondary
metrics cannot rescue failed primary log loss.

Estimate joint all-edge power from development participant-margin vectors by
the frozen deterministic resampling algorithm before confirmation opens.
Require at least 80% prospective joint power at the exact final confirmation
count under the precontact 0.030-nat design alternative while retaining 0.020
nats/trial as the minimum observed-effect gate. Because exact sign-test power is
not monotone in count, no smaller-count threshold substitutes for this exact
