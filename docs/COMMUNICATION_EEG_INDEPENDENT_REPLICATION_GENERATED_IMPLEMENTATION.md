# COMM-R0 Generated Replication Implementation

**Lane:** `COMM-R0-G`
**Date:** 2026-08-27
**Status:** implementation ready; official generated qualification inactive
**Parent:** `COMM-R0-REPLICATION-v0`

## Why this exists

The independent communication-EEG protocol is now executable on fictional
arrays before a real source is selected. This is an engineering gate, not a
shortcut to a scientific result. The implementation has no real-data loader,
download command, provider client, stream, device adapter, or release path.

The sidecar command is:

```bash
python -m neurodecodekit.comm_r0_cli plan
```

`qualify` remains fail-closed until a separate activation and proof record
bind this exact implementation after remote CI. There is no `real`, `download`,
`train`, `score`, or `live` command.

## Executable protocol

The generated full-control fixture contains 12 fictional participants, three
sessions per participant, four balanced classes, two repeats per class and
session, 288 rows, 14 channels, and one second of signal per row. Each row
retains item, participant, session, trial, fold, sample, time, sampling-rate,
channel-role, geometry, true-length, and padding-mask identities.

Every outer fold holds out exactly one participant with zero fit,
normalization, residualization, calibration, selection, or adaptation rows.
The predictor accepts only fold capabilities containing source targets and
held-out signals. Held-out targets live in a separate vault and cannot be
delivered until the complete prediction inventory has been validated and an
identity-bound committed-freeze capability has armed that vault.

One replay performs:

- 12 source-only nuisance-residualizer fits;
- 144 classifier or source-prior fits;
- 144 model/prior inference runs;
- 132 neural/control prediction sets;
- a neural-only aggregate prediction freeze;
- 48 provider-free language-control prediction sets after that freeze;
- one complete aggregate hash-only prediction freeze;
- one synthetic target delivery and one synthetic score; and
- zero post-target updates, provider calls, or reruns.

The class-destroying comparator fits every `K - 1` cyclic source-label shift.
For the four-class generated fixture this means shifts `+1`, `+2`, and `+3`,
with aligned held-out probabilities averaged only after all three fits. The
implementation also tests arbitrary shift mechanics separately from the fixed
four-class numerical fixture.

## Causality and controls

Each row emits an explicit causal timing record: event onset, frozen one-second
offset, decision timestamp, feature-availability timestamp, sample interval,
one-second left context, zero right context, and the presence of the offline
trial-boundary oracle. This can prove sample-causal feature accounting only.
It cannot prove continuous endpointing, runtime latency, or live decoding.

The full-control path includes priors, cue, timing, EOG, bilateral oral EMG,
posterior EEG, central EEG, nuisance context, residual EEG, and the complete
derangement ensemble. A separate route inventory marks unavailable partial-
route sensors and removes their arms; it never zero-fills or substitutes a
proxy and never upgrades a partial result to the full peripheral-adjusted
claim.

Language processing is deliberately provider-free. `language_only` is the
source prior. `neural_only` is the frozen neural candidate. Their normalized
product is compared with a target-blind within-participant/session item
rotation whose digest excludes participant identity and labels. Language-arm
results cannot alter the neural router.

## Qualification envelope

The future one-shot generated qualification requires two deterministic full
replays, all seven shortcut-placement fixtures, and all 16 refusal families
named by the parent contract. Its maxima are one CPU thread, one worker, one
numerical job, 300 seconds, 805,306,368-byte peak process-tree RSS, 33,554,432
generated input bytes, 67,108,864 private prediction bytes, 134,217,728
temporary bytes, and 1,048,576 public bytes.

The qualifier uses only committed local proof records. It performs no GitHub
or other network request during analysis. Temporary cleanup is inode-bound and
limited to the invocation-created directory. Publication is no-follow,
non-replacing, same-directory, and restricted to the exact registered result
path.
